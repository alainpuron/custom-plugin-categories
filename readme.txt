Organize your plugins into custom categories directly on the plugins page with drag-and-drop ordering.

== Description ==

Simple Plugin Organizer allows you to declutter your WordPress plugins page by creating custom categories, assigning plugins to them, and ordering them with a drag-and-drop interface.

* Inline category creation
* Drag-and-drop category sorting
* Native UI integration

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/simple-plugin-organizer` directory.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to your Installed Plugins page and start organizing!
